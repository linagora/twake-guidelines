# Rehearsal: twake-web (Twake Chat React, a reply in a room)

- **From the app (twake-space-chat):** Inter, primary `#006bd8`, primary dark `#0157ad`, own bubbles at 12 % primary on white, 16 px bubbles, 12 px buttons, the room list with filter chips and bottom nav, the logo and chat background.
- **Not the app:** icons are Lucide (stand-in for the app's icon set), the other rooms and avatars are placeholders, the font falls back to the system Inter when not installed.
- **Story:** a question lands, the user types and sends, ticks turn read, the other person types, the reply grows out of the dots. About 15 s, 1920 x 1080, plays once and holds.
- **Not checked:** dark theme. Compare one frame with the running app before publishing.
